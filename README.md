# Mystical Vision

### About
Mystical Vision is an AI/ML-powered image classification tool built using Python, designed to simplify data labeling, model training, and class prediction. Leveraging CNN-based image classifiers, it enables users to generate custom data models or utilize pre-trained models for predicting the class of unseen images. With a simple and adaptable user interface, it caters to a variety of practical applications, from medical imaging analysis to object and expression recognition.
